# 차근회계

전산회계운용사 2급을 처음 배우는 사람을 위한 개인 공부방.

## 포함 기능

- 재무회계 10단원 + 원가회계 10단원
- 책처럼 읽는 입문 교과서 20장, 80개 용어 풀이와 단계별 풀이 예제 20개
- 자체 제작 320문제: 입문 용어 80 + 기존 유형 160 + 숫자를 바꾼 반복 80
- 각 장의 본문, 처리 이유, 혼동 사례, 기출 읽는 법
- 실제 기출 원문 5회차 바로가기와 전체 회차 목록
- 카페의 현금·커피 머신·대출 변화를 보는 예시
- 과목·단원·단계별 문제 선택
- 재무회계 20문제와 원가회계 20문제, 60분 모의시험
- 과목별 과락과 평균점수를 구분하는 채점
- 오답노트·별표·메모·진도 저장
- 진행 중 시험 저장, 브라우저를 닫아도 흐르는 제한시간
- JSON 백업 및 불러오기, 큰 글씨
- 모바일·PC 반응형 화면

## 문제 출처 구분

**사이트 내 320문항은 자체 제작 연습문제이며, 실제 기출·복원문제가 아닙니다.**
실제 과거 기출은 외부 CBT 원문으로, 공식 공개형·출제기준은 대한상공회의소로 연결합니다.
출판사의 복원문제 안내는 별도로 표시합니다. 외부 교재·CBT 문제를 복사하여 재배포하지 않았습니다.
자체 제작 문제는 기초 이해와 유형 연습을 위한 것이며 전체 세부 출제범위를 대체하지 않습니다.
실제 회계 프로그램 실기는 공식 프로그램과 공개형 자료로 따로 연습해야 합니다.

확인 기준: 2026-11-15. 공식 시험 규정·출제기준·프로그램 변경은 대한상공회의소 안내를 우선합니다.

## GitHub Pages에 올리기

1. GitHub에 `accounting-study`라는 새 저장소를 만듭니다.
2. 이 폴더의 **index.html**을 저장소 맨 위에 올립니다. 다른 파일은 필수가 아닙니다.
3. 저장소 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택합니다.
4. **main / (root)**를 선택하고 **Save**합니다.
5. Pages 설정에 표시되는 사이트 주소로 접속합니다. 최초 반영에는 시간이 걸릴 수 있습니다.

GitHub 무료 개인 계정의 Pages는 보통 public 저장소가 필요합니다. HTML에는 사용자 개인정보나 학습기록이 포함되어 있지 않습니다.
학습기록은 방문자의 브라우저에만 저장되므로 GitHub로 전송되지 않습니다. 외부 링크와 웹폰트는 인터넷을 사용합니다.

## 파일 구성

- `index.html`: 그대로 업로드하여 사용할 수 있는 단일 HTML
- `index.template.html`: 화면·기능 편집용 소스
- `content.json`: 생성된 단원·문항 데이터
- `build_content.py`: 기존 160문항 편집 원본
- `book_content.py`: 교과서 본문·추가 160문항 편집 원본
- `build.py`: 편집 원본에서 index.html 생성
- `verify.cjs`: 채점·진도·문제 데이터 검증

수정 후 `python build.py`로 생성하고 `node verify.cjs`로 핵심 동작을 확인합니다.
설치·API 키·서버가 필요 없습니다. 외부 폰트가 차단되면 시스템 글꼴로 표시합니다.
